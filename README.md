## ⚡ Engineering Standards

- **Zero-Allocation Core**: Core gameplay loops operate with 0-byte Garbage Collection allocations to guarantee locked 60 FPS performance.
- **Tactile Game Feel**: Fine-tuned visual micro-trauma, frame pauses, and acoustic pitch modulation.
- **Modular Pipelines**: ScriptableObject architectures for level definitions, obstacles, and remote balance configurations.

## 🌐 GitHub Pages Deployment

This site is built with modern, semantic, dependency-free HTML, CSS, and Vanilla JavaScript. All asset references are relative, making it fully ready for direct deployment to GitHub Pages.

To enable GitHub Pages:
1. Go to repository **Settings** &rarr; **Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch `main` and folder `/ (root)`.
4. Click **Save**.
